# vibe-only

Автономная сборка одной страницы `static/vibe.html` («vibe mode» из основного
стенда SIP-тестов). Отдельный Go-модуль: только stdlib, без sipgo и без кода
тестирования. Страница полностью самодостаточна (CSS/JS внутри HTML, без
запросов к серверу), сервер лишь раздаёт её на любом пути.

## Сборка и запуск

```bash
go build -o vibe-only .
./vibe-only [-addr :8090]
# или без сборки:
go run . [-addr :8090]
```

Затем открыть http://localhost:8090

## Обновление из основного стенда

`static/vibe.html` — копия `../internal/webui/static/vibe.html`. После правок
в оригинале — запустить:

```bash
./sync.sh
```

Скрипт копирует страницу, убирает из копии ссылку
`<a href="/">← назад к тестам</a>` в `<header>` (здесь нет страницы тестов, на
которую можно вернуться — любой путь отдаёт саму страницу), меняет заголовок
вкладки на `🎧 vibe mode` (здесь это самостоятельная страница, а не «SIP Tester —
vibe mode») и пересобирает бинарь `vibe-only`.
