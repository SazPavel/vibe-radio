# vibe-only

Автономная сборка одной страницы `static/vibe.html` («vibe mode»). Отдельный Go-модуль: только stdlib, без sipgo и без кода
тестирования. Страница полностью самодостаточна (CSS/JS внутри HTML, без
запросов к серверу), сервер лишь раздаёт её на любом пути.

## Сборка и запуск

```bash
go build -o vibe-only .
./vibe-only [-addr :8090]
# или без сборки:
go run . [-addr :8090]
```

Затем открыть http://localhost:8090
